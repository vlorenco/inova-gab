# InovaGAB - Product Overview

## Project Purpose
InovaGAB is an Android mobile application developed under the FIAP (Faculdade de Informática e Administração Paulista) umbrella. It is a greenfield Jetpack Compose-based Android app, currently in its initial scaffolding phase.

## Value Proposition
- Modern Android UI built entirely with Jetpack Compose and Material 3
- Edge-to-edge display support for a full-screen, immersive experience
- Clean architecture foundation ready for feature development

## Key Features (Current)
- Edge-to-edge layout via `enableEdgeToEdge()`
- Material 3 theming with custom color scheme and typography
- Scaffold-based screen structure with proper inset handling
- Composable preview support for rapid UI iteration

## Target Users
- FIAP students and faculty interacting with the GAB (likely "Gestão de Atividades/Bolsas" or similar academic management) system
- Internal academic/administrative users within the FIAP ecosystem

## Use Cases
- Foundation for building academic management or innovation-related features
- Demonstrates modern Android development practices with Compose
